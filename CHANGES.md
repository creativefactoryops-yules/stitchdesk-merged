# Stitch Voice Chat v2.1 — changes (for Muse to apply or deploy)

© 2026 Yules · CreativeFactory.studio · buildyou. All rights reserved.

Source: `stitch-v2.1.zip` (folder `app-v2.1/`, no node_modules or dist). Built from v2.0 (the code now live at
https://stitch-voice-chat.vercel.app). Nothing was pushed, deployed, or signed up for.

## How to deploy
1. Unzip over the repo (or replace the folder). Run `npm install`, `npm test`, `npm run build`.
2. Push to the branch Vercel deploys. No new environment variables. Same `GEMINI_API_KEY`; Supabase and Cloudflare stay optional.
3. After deploy, open `/s/maple-demo` on a phone and check: copper robot, Voice On button, chips, lime SEND, trial bar, footer.

## 2. Voice (same as the old app, made safe for TalkBack)
- Voice On by default, saved as `stitch_voice` (the old key). Same voice settings: male-sounding voice if the phone has one,
  rate 0.95, pitch 0.85. The greeting is spoken about 1 second after the page opens when Voice is On (most browsers block
  this until the first tap; replies after that are spoken).
- LISTEN works like before: the words appear in the box while you talk (en-CA), then send themselves. It now stops Stitch
  talking first, so the mic does not hear Stitch.
- No double-speak: with Voice On, the reply is spoken and the screen-reader live region stays quiet. With Voice Off, the
  screen reader announces only the newest reply. If the phone cannot speak, the reply is announced instead.
- Toasts ("Listening… speak now", "Copied!") are also sent to the screen reader once.

## 3. The v2 brain stays underneath
- Full conversation to `/api/chat`, the self-filling job sheet, memory across reloads.
- The old greeting is saved as turn one, so the server sees Stitch already introduced itself and never re-introduces.
- `shared/prompt.ts`: two lines added: use Canadian spelling, and repeat measurements back with their units.
  Not tested against real Gemini (no key here). Everything else in the prompt is unchanged.

## 4. Claims fixed so nothing overstates
- Old blurb said "pebbled cognac lot #453, HR foam, boost 2cm… voice works on deploy, offline brain baked in". Replaced with
  a plain description of what Stitch does at this shop. Placeholder no longer mentions lot #453 or King Textiles.
- The old picture card said "AR measure 85.6mm ref card… Ollama baked in". Replaced with plain tips (measure with a tape,
  prices are a range the shop confirms, and in demo mode the chat is saved on this phone only).
- Removed the old canned "offline brain" replies and Ollama calls. If the AI is down, Stitch says it is offline.
- "COPY LINK ?ref=" (no referral tracking exists) is now "COPY LINK": copies this chat page's link.
- "COPY e-Transfer" copied Yules' email on a shop's client page. It now copies the shop's own deposit email (labelled
  "demo address" in demo mode).
- "Set Up + Activate" used to show "Shop activated" and do nothing. It now opens the shop desk and fills the shop name in
  the real set-up form (in demo mode it says it is opening the demo desk).
- Subscribe: the old "I've paid — unlock 30 days" button unlocked itself on trust. Now the panel says plainly that online
  payment is not on, nothing is charged, and this button unlocks nothing. It gives the e-Transfer details (forcebuildyou@gmail.com)
  and says Yules switches the plan on by hand. It no longer blocks clients with a trial form on their first visit.
- Trial bar counts down from the shop's real trial start date.
- Photo tab: when Cloudflare is off (live now), the title is "Style preview" and it says it is made from the description,
  not an edit of the photo. The photo is not sent to the server in that case. Photo hint no longer says "private to the shop".
- Preview error now says the free image service allows about 1 picture every 45 seconds.
- Demo mode notes added where data only lives on this phone: banner, booking link, My job, shop "quote sent".
- Home page no longer promises "before and after previews from a photo" without the photo service.
